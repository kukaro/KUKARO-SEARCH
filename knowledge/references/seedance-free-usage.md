# Seedance 무료 사용 범위

## 웹 플랫폼 (Dreamina) — 유일한 실질적 무료 옵션

| 항목 | 내용 |
|---|---|
| **일일 무료 크레딧** | 120~225 크레딧/일 (시기에 따라 변동) |
| **리셋** | 매 24시간 자동 갱신 |
| **카드 등록** | 불필요 |
| **제한** | 모든 Dreamina 도구(이미지/비디오)와 크레딧 공유 |

### 무료로 만들 수 있는 영상 (일일 기준)

| 해상도 | 크레딧/초 | 4초 영상 비용 | 하루 가능 편수 (120cr 기준) |
|---|---|---|---|
| 480p | ~3cr/초 | ~12cr | ~10편 |
| 720p | ~6cr/초 | ~24cr | ~5편 |
| 1080p | ~15cr/초 | ~60cr | ~2편 |

> 테스트/학습 용도로는 충분. 본격 제작은 유료 전환 필요.

## API — 무료 없음

| 플랫폼 | 무료 여부 | 최소 비용 |
|---|---|---|
| **Together AI** | 무료 티어 없음 | 최소 $5 선불 충전 |
| **MuAPI** | 무료 없음 | Pro/Business 플랜 필수 |
| **Kie.ai** | 가입 시 80cr 제공 | Seedance 2.5 최소 1회(112cr)에 부족 |
| **AdSkull** | 가입 시 50cr 제공 | 480p 4초 1회 가능 |
| **SeedVideo AI** | 가입 시 5cr 제공 | Seedance 2.5 불가 (2.0 Mini만 가능) |

## 기타 무료 접근 경로

- **Together AI 스타트업 프로그램**: 심사 통과 시 최대 $50K 크레딧 (별도 신청)
- **Dreamina 일일 리셋 활용**: 매일 조금씩 생성하면 카드 없이 지속 사용 가능
- **Kubeez**: 가입 크레딧으로 제한적 테스트 가능

## 결론

| 목적 | 추천 |
|---|---|
| 테스트/학습 | Dreamina 무료 (매일 리셋) |
| 소량 제작 | Dreamina Mini ($14.9/월) |
| API 개발/통합 | Together AI ($5 최소 충전) |
| 고해상도 대량 | MuAPI Pro 플랜 |
