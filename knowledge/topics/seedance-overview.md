# Seedance (씨댄스) 개요

## 정체

- **정식 명칭**: Seedance 2.5 (최신), Seedance 2.0 (이전 버전)
- **한국어명**: 씨댄스
- **개발사**: ByteDance (바이트댄스, TikTok 모회사)
- **유형**: 통합 멀티모달 AI 영상 생성 모델
- **배포 방식**: ByteDance가 직접 판매하지 않음. 서드파티 플랫폼을 통해 배포

## 핵심 능력

| 항목 | 상세 |
|---|---|
| 최대 단일 생성 | 30초 (오디오+비디오) |
| 연장 | Extend 기능으로 +2 세그먼트 추가 가능 |
| 참조 이미지 | 최대 30장 |
| 참조 비디오 | 최대 10개 |
| 참조 오디오 | 최대 10개 |
| 특수 참조 | 그린스크린, 화이트 배경 (카메라/조명 정밀 제어) |
| 편집 | 타임스탬프 기반 부분 편집 (전체 재생성 불필요) |
| 프레임 제어 | 첫 프레임, 마지막 프레임, 또는 양쪽 키프레임 |
| 언어 지원 | 10개 이상 (한국어 포함) |
| 오디오 | 자동 생성, 동기화, 립싱크 가능 |
| 해상도 | 480p, 720p (네이티브) / 1080p, 4K (720p 기반 업스케일) |
| 길이 범위 | 4~30초 (정수) |
| 화면 비율 | 16:9, 9:16, 1:1, 4:3, 3:4, 21:9, 9:21 |

## 2.0 대비 2.5 개선 사항

- 단일 클립: 15초 → 30초
- 참조 용량: 이미지 9/비디오 3/오디오 3 → 30/10/10
- 타임스탬프 기반 부분 편집 추가
- 한국어 및 다국어 네이티브 지원
- 캐릭터 일관성 향상 (얼굴, 의상, 배경 연속성)

## 주요 워크플로우 (6가지)

1. **Text-to-Video** — 텍스트로 영상 생성
2. **Image-to-Video** — 이미지를 영상으로 애니메이션
3. **First & Last Frame** — 시작/끝 키프레임 지정 전환
4. **Omni Reference** — 이미지+비디오+오디오 복합 참조
5. **Video Edit** — 기존 영상 타임스탬프 기반 편집
6. **Video Extend** — 영상 이어 생성

## 경쟁사 비교: Seedance 2.5 vs Kling 2.5 Turbo

| 항목 | Seedance 2.5 | Kling 2.5 Turbo |
|---|---|---|
| 단일 출력 | 최대 30초 | 5~10초 클립 |
| 참조 | 최대 50개 (30 img + 10 vid + 10 audio) | 플랫폼 의존 이미지 참조 |
| 편집 | 타임스탬프 기반 부분 편집 | 클립별 재생성 |
| 오디오 | 네이티브 생성 + 립싱크 | 효과음/오디오 생성 |
| 최대 해상도 | 480p~4K (플랫폼 의존) | 1080p |
| 최적 용도 | 풀 내러티브, 광고 | 빠른 숏폼 클립 |
