# Seedance로 할 수 있는 것

## 1. 텍스트→비디오 (Text-to-Video)

텍스트 프롬프트만으로 최대 30초 영상 생성.

**활용 예:**
- SNS 숏폼 콘텐츠 (TikTok, Reels, Shorts)
- 컨셉 영상 프로토타입
- 스토리보드 시각화

## 2. 이미지→비디오 (Image-to-Video)

정지 이미지를 움직이는 영상으로 변환.

**활용 예:**
- 제품 사진을 동영상 광고로 전환
- 일러스트/아트워크 애니메이션화
- 건축 렌더링에 카메라 무빙 추가

## 3. 키프레임 전환 (First & Last Frame)

시작 이미지와 끝 이미지를 지정하면 자연스러운 전환 영상 생성.

**활용 예:**
- Before/After 전환 영상
- 씬 전환 효과
- 모핑 애니메이션

## 4. 복합 참조 생성 (Omni Reference)

이미지 30장 + 비디오 10개 + 오디오 10개까지 참조하여 생성.

**활용 예:**
- 특정 캐릭터/브랜드 스타일 유지하며 새 장면 생성
- 댄스 모션 참조 + 캐릭터 이미지 + 배경음악으로 뮤직비디오
- 기존 브랜드 영상 톤앤매너 유지하며 새 광고 제작

## 5. 비디오 편집 (Video Edit)

기존 영상의 특정 구간만 타임스탬프 기반으로 수정.

**활용 예:**
- 낮 장면을 밤으로 변경
- 배경/의상/색감 변경
- 날씨/계절 교체

## 6. 비디오 연장 (Video Extend)

기존 영상의 끝에서 이어서 새로운 장면 생성. +2회 연장 가능.

**활용 예:**
- 5초 클립을 15초 이상으로 확장
- 스토리 연속성 유지하며 다음 장면 생성

## 7. 캐릭터 일관성 (Character Consistency)

캐릭터 시트를 먼저 생성 → 이를 기반으로 다수 영상에서 동일 캐릭터 유지.

**활용 예:**
- 시리즈물/에피소드 영상 제작
- 브랜드 마스코트 활용 광고
- 가상 인플루언서 콘텐츠

## 8. 립싱크 + 오디오 동기화

음성/음악에 맞춰 캐릭터 입모양과 동작 자동 동기화.

**활용 예:**
- 음악 뮤직비디오
- 나레이션 기반 설명 영상
- 팟캐스트/라디오 콘텐츠 영상화

## 산업별 활용

| 산업 | 활용 |
|---|---|
| **마케팅/광고** | 제품 광고, SNS 콘텐츠, 브랜드 영상 |
| **엔터테인먼트** | 뮤직비디오, 숏폼 드라마, 애니메이션 |
| **교육** | 교육 영상, 시뮬레이션, 역사 재현 |
| **이커머스** | 제품 시연, 사용법 영상, 리뷰 영상화 |
| **부동산** | 가상 투어, 건축 시각화 |
| **게임** | 시네마틱 트레일러, 컨셉 영상 |

## 제한 사항

- 최대 단일 생성: 30초 (연장으로 더 길게 가능)
- 네이티브 해상도: 480p, 720p (1080p/4K는 업스케일)
- ByteDance 직접 판매 없음 — 서드파티 플랫폼 필수
- 유료 플랜 필요 (무료 크레딧으로 테스트 가능)
- 타인 얼굴/음성/상표 무단 사용 시 IP 문제 발생 가능
